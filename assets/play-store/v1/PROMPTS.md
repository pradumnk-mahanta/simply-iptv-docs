# Generation prompts

Mode: built-in image-generation tool. References: existing Simply IPTV banner and splash logo; subsequent assets use the generated icon as a visual reference.

## icon

```
Use case: logo-brand
Asset type: Google Play store app icon for Simply IPTV.
Use the attached existing banner and splash logo as brand reference images, not as edit targets. Create a polished square version of this exact brand identity.
Output a single square 1024x1024 image, full-bleed opaque midnight navy background (#060B18) right to all four square corners. No rounded outer icon mask, no external shadow or margin.
Place a centered, flat deep royal navy rounded rectangle with a thin, precise electric cyan (#00E5FF) perimeter, a restrained inner glow only; it should occupy about 78% of the canvas width and 60% of the height. Inside, typography is the hero: exact text "Simply" above exact text "IPTV". Simply in clean white geometric sans serif, IPTV in very bold geometric sans serif, the letters IP white and TV cyan. Both lines flush left at the same baseline x origin, just as in reference. Typography should be large, extremely crisp and readable at small app-icon size, with ample safe padding. Keep all important art in central 78% of square.
Style: flat, premium broadcast brand, minimalist, no textures, no smoke, no ribbons, no 3D bevels, no fake mockup. Preserve recognizable existing brand. No additional text, symbols, badges, watermarks or third-party logos. This is actual production icon art, not a presentation of an icon.
```

